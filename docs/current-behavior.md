# 현재 동작 기준

이 문서는 급여 계산 로직을 순수 함수로 분리하기 전의 현재 동작을 기록한
기준선이다. 아래 결과는 현재 `src/hooks/useSalary.ts`와
`src/lib/time.ts`의 구현을 기준으로 계산했다.

## 공통 기본 설정

기준 사례는 `src/app/page.tsx`의 `defaultSettings`를 사용한다.

| 설정 | 값 |
| --- | ---: |
| 기본 시급 | 10,320원 |
| 추가수당 | 0원 |
| 식대 | 0원 |
| 연장/야간 가산 배율 | 1.5배 |
| 연장수당 적용 | false |
| 야간수당 적용 | false |
| 주휴수당 적용 | false |
| 추가수당 적용 | false |
| 공제 적용 | false |
| 각 보험 및 세금 적용 | false |

따라서 아래 기준 사례에서는 계산된 시간 항목은 표시되지만, 연장수당,
야간수당, 주휴수당, 공제는 설정상 금액에 반영되지 않는다.

## 사례 3: 날짜가 넘어가는 야간 근무

결과:

`diffMinutes`가 종료 시간이 시작 시간보다 이른 경우 다음 날로 간주하며,

제한한다.

## 사례 5: 여러 날짜의 근무 기록

입력:

- `2026-07-27`, `09:00`~`18:00`, 휴게 60분
- `2026-07-28`, `09:00`~`18:00`, 휴게 60분
- `2026-07-29`, `09:00`~`18:00`, 휴게 60분
- `2026-07-30`, `09:00`~`18:00`, 휴게 60분
- `2026-07-31`, `09:00`~`18:00`, 휴게 60분

결과:

| 항목 | 결과 |
| --- | ---: |
| 총 근무시간 | 40시간 0분 (2,400분) |
| 정규 근무시간 | 40시간 0분 (2,400분) |
| 연장 근무시간 | 0분 |
| 야간 근무시간 | 0분 |
| 주휴수당 시간 | 8시간 0분 (480분) |
| 기본급 | 412,800원 |
| 주휴수당 | 0원 (적용 설정 false) |
| 총 지급액 | 412,800원 |
| 실수령액 | 412,800원 |

다섯 기록은 같은 월요일 시작 주에 속한다. 주간 합계 2,400분을
5일로 나눈 값인 480분이 `weeklyAllowanceMinutes`가 된다. 주휴수당
금액은 `applyWeeklyAllowance`가 true일 때만 지급액에 포함된다.

## 데이터 저장과 복원

현재 구현에는 `localStorage`, 서버 API, 데이터베이스, 파일 저장 또는
복원 기능이 없다. `entries`와 `settings`는 `HomePage`의 React 상태에만
존재하므로 페이지를 새로고침하면 초기값으로 돌아간다.
